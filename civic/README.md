# H.W. Nichols III — Civic Research Portal (Version 2)

This package adds an independent civic microsite under `civic/` without changing the RD Quarters homepage.

## Upload
1. In GitHub open repository `rdquarters.com` and folder `civic`.
2. Upload **index.html**, **style.css**, and **presentation.html** from this package into `civic/` (replace the older civic/index.html).
3. Commit the changes to main.
4. Visit https://rdquarters.com/civic/ and https://rdquarters.com/civic/presentation.html after Pages updates.

Keep your existing images and README if you wish. No need to replace root index.html.

## Limitations
- This is a static educational site, not a working discussion forum or auto-updating news service.
- Local meeting timeline, report PDF, and portrait are intentionally not invented or linked until verified.
- The sources are initial research pointers, not an exhaustive legal review.
- Existing civic photo filenames are preserved; choose one before embedding it.
